# Make the AI Judge Laugh

One-line office joke entry for the [make.fun bounty](https://make.fun/bounty/u-rama-melon-make-the-ai-judge-laugh-302d0825).

`main.py` (standard library only) writes a single joke about office life to
`/output/entry.txt`. The entry:

> My boss said we're a family, so I asked when the family reunion comes with a raise. Now I'm in a meeting about my attitude.

Run it with `python3 main.py`.
